# Backreef extensions

Source plugins for Caye: torrent search, manga, light novels and online video.

## Add them to Caye

1. Open **Plugins**, then **Repositories**.
2. Add `backreef/extensions`.
3. Open **Browse** and install the plugins you want.

## Plugins

| Plugin | Adds |
| --- | --- |
| AnimeTosho | Anime torrent and NZB search |
| Nyaa | Anime torrent search |
| Nyaa literature | Manga and book torrent search |
| The Pirate Bay | Torrent search for every media kind |
| WeebCentral | Manga chapters |
| NovelFire | Light novel chapters |
| Anikoto | Anime episodes to watch online |

Each plugin asks for its sites when you install it. These plugins only search and read the sites they name. They host nothing.
